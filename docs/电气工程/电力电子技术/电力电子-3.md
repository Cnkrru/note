## 一、单相可控整流电路
### 1. 单相半波可控整流电路
#### 1.1 结构原理
1. 变压器:交换电压，电气隔离
    - 一二侧电压瞬时值u1,u2
    - 一二侧电压有效值U1,U2
2. 晶闸管:控制电路导通
#### 1.2 带阻性负载
1. 电路图参数
    1. u2 = uVT+ud
    2. uVT:晶闸管压降
    3. ud:负载电压(直流输出电压)
2. 特点
    1. 纯阻性负载，ud波形与id完全相同
    2. 对电流变化没有阻碍作用，变压器进入负周期时，不会追补回来一些电压
3. 参数
    1. Ud
        - ud的平均值
        - Ud = 0.45*U2*[(1+COSa)/2]
    2. 调相范围
        - 0~180
        - 通过控制触发脉冲的相位来控制直流输出电压的大小(相控方式)
#### 1.3 带阻感性负载(电感>>电阻)
1. 电路图参数
    1. u2 = uVT+ud
    2. uVT:晶闸管压降
    3. ud:电感和电阻的负载电压
    4. id:流过电感电阻的电流
2. 特点
    1. 阻感性负载，阻负责消耗能量，感负责存储能量，总能量不变的情况下，感存储越多，在晶闸管电压反向时，延续导通的时间越长，如果存电感电路，电阻完全为0，此时晶闸管正负半周期都完全导通，arctan(wL/R)称为阻感角
    2. 阻感角一定，触发角越大，电感能存储的能量越少，晶闸管进入反向时，电流续流时间就越短
    3. 触发角一定，阻感角越大，电感能存储的能量越多，晶闸管进入反向时，电流续流时间就越长
#### 1.4 带阻感性负载(接续流二极管)
> 接续流二极管的情况下，晶闸管进入反向时，电流从续流二极管与阻感形成回路，不影响晶闸管，晶闸管正常关断
参数:
1. 移相范围:0~180
2. 晶闸管承受最大反向电压:根号二U2
3. 续流二极管承受电压-ud，最大反向电压根号二U2
#### 1.5 单相半波可控整流电路的特点
1. 简单,输出脉动大
2. 变压器二次电流中含直流分量,造成变压器铁芯磁化
    - 为使变压器铁芯不饱和，需要增大铁芯截面积，增大了设备的容量
### 2. 单相桥式全控整流电路
#### 2.1 带阻性负载
1. 参数
    1. 晶闸管最大正向电压:0.707*U2
    2. 晶闸管最大反向电压:1.414*U2
    3. 整流电压平均值Ud:0.9*U2*[(1+cos(a))/2]
    4. 整流电流平均值Id:Ud/R
    5. 晶闸管电流均值I_dVT:Id/2
    5. 移相范围:0~180
#### 2.2 带阻感性负载
1. 参数
    1. 晶闸管最大正向电压:1.414U2
    2. 晶闸管最大反向电压:1.414U2
    3. 整流电压平均值Ud:0.9*U2*cos(a)
    4. 晶闸管电流平均值:Id/2
    5. 晶闸管电流有效值:0.707Id
    6. 移相范围:0-90
### 2.3 带反电动势负载
1. 参数
    1. ud=u2
    2. id=ud-E/R
#### 2.4 单相桥式全控整流电路的特点
1. 变压器二次绕组中，正负两个半周电流方向相反且波形对称，平均值为0，不存在直流分量，铁芯不磁化
### 3. 单相全波可控整流电路
#### 3.1 单相全波可控整流电路的特点
1. ud的波形与单相全控桥一样
2. 变压器不存在直流磁化问题
> 与单相全控桥整流电路的区别
1. 单相全波可控整流电路的变压器二次侧带中心抽头，成本高
2. 该电路用两个晶闸管，单相全控桥电路用四个
3. 该电路晶闸管承受最大电压为2.828U2,单相全控桥电路为1.414U2

## 二、三相可控整流电路
### 1. 三相半波可控整流电路
#### 1.1 带阻性负载
1. 接线
    - 变压器二次侧为了得到零线，必须星接
    - 一次侧为了避免谐波进入电网，角接
2. 角度关系
    1. 一次周期，每组晶闸管导通120
    2. 30°:波形连续与断续的分界
3. 参数
    1. 移相范围:0~150
    2. 整流电压平均值(a<30)
        - 1.17*U2*cos(a)
    3. 整流电压平均值(a>30)
        - 0.675[1+cos(Π/6+a)]
    4. 负载电流平均值
        - Ud/R
    5. 晶闸管承受的最大反向电压
        - 根号三*根号二*U2
    6. 晶闸管阳极与阴极间的最大电压
        - 根号二*U2
#### 1.2 带阻感性负载
1. 参数
    1. 移相范围:0~90
    2. 整流电压平均值
        - 1.17*U2*cos(a)
    3. 晶闸管电流有效值
        - I_VT = I2 = 0.577*Id
    4. 晶闸管额定电流
        - I_VT/1.57
    5. 晶闸管最大正向电压
        - 2.45U2
    6. 晶闸管最大反向电压
        - 2.45U2
2. 特点
    - 变压器二次侧有直流分量，会导致铁芯磁化
### 2. 三相桥式全控整流电路
#### 2.1 带阻性负载
1. 角度关系
    1. 波形每段60°
    2. VT_1~6,每个占60°
    3. 共阴/阳(1-2-5,2-6-4),依次相差120°
    4. 同一相上下两臂,相差180°
2. 参数
    1. 连续断续分界:60
    2. 移相范围:0~120
#### 2.2 带阻感性负载
1. 参数
    1. 移相范围:0~90
    2. 整流输出电压(a<60)
        - 2.34*U2*cos(a)
    3. 整流输出电压(a>60)
        - 2.34*U2*[1+cos(Π/3+a)]
    4. 变压器二次侧电流有效值
        - 0.816Id
## 三、变压器漏感对整流电路的影响
1. 原因
由于漏感存在，换相时，一个晶闸管关断器件，另一个晶闸管打开，会出现双管同时导通的情况
- 双管同时导通这段时间称之为换相重叠角
2. 参数
    1. 整流电压
        - ud = ua+ub/2
    2. 换相压降
        - U = 3*X_B*I_d/2Π
    3. 换相重叠角
        - 公式太长
        - 结论:
            - Id越大，换相角越大
            - X越大，换相角越大
            - a<=90,a越小，换相角越大
3. 结论
    1. 出现换相重叠角，整流输出电压平均值降低
    2. 整流电路工作状态增多
    3. 晶闸管电流变化率减小，有利于晶闸管安全开通
    4. 换相时，晶闸管电压出现缺口，可能导致晶闸管误导通
    5. 换相使电网电压出现缺口，可能成为干扰源
