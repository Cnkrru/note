## 一、降压斩波电路
1. 工作原理
    - 一个周期内，V(晶闸管)先导通一段时间 $t_{on}$，此时 E 给电感 L、电阻 R、电机 M 供电，之后 V 关断，电感释放能量，经过续流二极管给 R、M 供电，过 $t_{off}$ 后，进行下一个周期，V 重新导通，循环往复
2. 电路图
3. 参数
    1. 负载电压($U_o$)
        - $\dfrac{t_{on}}{t_{on}+t_{off}}E$
    2. 负载电流
        - $\dfrac{U_o-E_M}{R}$($E_M$ 为反电动势)
    3. 输出电流最大值的瞬时值
        - $\left(\dfrac{e^{-\alpha\rho}-1}{e^{-\rho}-1}-m\right)\dfrac{E}{R}$
    4. 输出电流最小值的瞬时值
        - $\left(\dfrac{e^{\alpha\rho}-1}{e^{\rho}-1}-m\right)\dfrac{E}{R}$
4. 电流连续条件(L比较小才需要判断，L极大不需要)
    - $m = E_M/E$
    - $\tau = L/R$($\tau$ 为时间常数)
    - $\rho = T/\tau$
    - $\alpha\rho = t_{on}/\tau$
        - $\dfrac{e^{\alpha\rho}-1}{e^{\rho}-1} > m$ 则连续
## 二、升压斩波电路
1. 工作原理
    - 电感 L 和电容 C 很大，刚开始，V 导通，E 只给电感 L 供电，供电 $t_{on}$ 这么长时间，而负载由电容之前存储的能量提供能量，$t_{on}$ 过后，V 断开，E 和 L 共同给 C 与负载供电，供电 $t_{off}$ 这么长时间，V 再导通，循环往复
2. 电路图

3. 结构功能
    1. 电感:储存电能
    2. 电容:保持输出电压
4. 参数
    1. 负载电压平均值
        - $U = \dfrac{t_{on}+t_{off}}{t_{off}}E$
            - $\beta = \dfrac{t_{off}}{T}$
    2. 输出电流平均值
        - $I = U/R$
    3. 电源电流平均值
        - $I_0 = \dfrac{U}{E}I$
