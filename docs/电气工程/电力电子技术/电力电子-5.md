## 一、降压斩波电路
1. 工作原理
    - 一个周期内，V(晶闸管)先导通一段时间t_on,此时E给电感L，电阻R，电机M供电，之后V关断，电感释放能量，经过续流二极管给R,M供电，过t_off后，进行下一个周期，V重新导通，循环往复
2. 电路图
3. 参数
    1. 负载电压(U_on)
        - (t_on/t_on+t_off)*E
    2. 负载电流
        - U_on - E_M(反电动势)/R
    3. 输出电流最大值的瞬时值
        - (((e^(-αρ)-1)/(e^(-ρ)-1)) - m)*(E/R)
    4. 输出电流最小值的瞬时值
        - (((e^(αρ)-1)/(e^(ρ)-1)) - m)*(E/R)
4. 电流连续条件(L比较小才需要判断，L极大不需要)
    - m = E_m/E
    - t = L/R
    - ρ = T/t
    - αρ = t_on/t
        - ((e^(αρ)-1)/(e^(ρ)-1)) > m 则连续
## 二、升压斩波电路
1. 工作原理
    - 电感L和电容C很大，刚开始，V导通，E只给电感L供电，供电t_on这么长时间，而负载由电容之前存储的能量提供能量，t_on过后，V断开，E和L共同给C与负载供电，供电t_off这么长时间，V再导通，循环往复
2. 电路图

3. 结构功能
    1. 电感:储存电能
    2. 电容:保持输出电压
4. 参数
    1. 负载电压平均值
        - U = (t_on+t_off/t_off)*E
            - β = t_off/T
    2. 输出电流平均值
        - I = U/R
    3. 电源电流平均值
        - I0 = (U/E)*I
