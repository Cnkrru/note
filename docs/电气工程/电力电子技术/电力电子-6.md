## 一、交流调压电路
### 1. 分类
1. 直接方式

        - 改变电压电流
        - 改变电路通断周期
    2. 变频电路
        - 改变电路频率
2. 间接方式
### 2. 交流调压电路(单相)
#### 2.1 电阻负载
1. 参数计算
    - $U_o = U_i\sqrt{\dfrac{\sin 2\alpha}{2\pi}+\dfrac{\pi-\alpha}{\pi}}$
    - $I_o = U_o/R$
    - $I_{VT} = I_o/\sqrt{2}$
    - $\lambda = U_o/U_i$
2. 特性
    1. 移相范围:$0°\sim180°$
    2. $\alpha$ 增大，电压有效值减小，$\lambda$ 减小
### 2.2 阻感负载
1. 参数计算
    1. 临界角 $\varphi = \arctan\dfrac{X_L}{R}$
        - 移相范围:$\varphi\sim\pi$
        - $\tan\varphi = \dfrac{\omega L}{R}$
        - $\cos\varphi = \lambda$(功率因数)
    2. 如果触发角小于临界角 $\varphi$(相当于晶闸管不存在了)
        - 输出电压 = 输入电压
        - 负载电流:$I_o = I_{in} = U/Z$
        - 功率因数:$\lambda = R/Z$
    3. 如果触发角大于临界角 $\varphi$(不考)
### 3. 其他交流电力控制电路
#### 3.1 交流调功电路
1. 交流调压电路:调整晶闸管触发角，控制每个周期内的导通时刻，来控制输出电压有效值
2. 交流调功电路:在周期分隔的 0 点进行控制，开通 n 个周期，关断 m 个周期，算 m+n 个周期的功率
#### 3.2 交流电力电子开关(不考)

## 考点
1. 画波形
2. 阻性负载
    - $U_o$，$I_o$，$I_{VT}$，$\lambda$
3. 阻感负载
    - 角度临界值，$U_o$，$I_o$，$I_{VT}$
4. 调压/调功的区别与适用
    - 调压:适用于调光，电动机(调完电压立马变化)
    - 调功:适用于调热(变化慢，调电压影响不大的)
