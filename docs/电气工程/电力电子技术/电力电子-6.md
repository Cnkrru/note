### 2. 交流调压电路(单相)
#### 2.1 电阻负载
1. 参数计算
    - U_o = U_i*(sin(2a)/2Π + Π-a/Π)
    - I_o = U_o / R
    - I_vt = I_o / 根号2
    - λ = U_o / U_i
2. 特性
    1. 移相范围:0~180
    2. a增大，电压有效值减小，λ减小
### 2.2 阻感负载
1. 参数计算
    1. 角度k = arctan(X_L/R) 
        - 移相角:k ~ Π
        - tank = W_L/R
        - cosk = λ = 功率因数角
    2. 如果角度小于移相角最小值(相当于晶闸管不存在了)
        - 输出电压 = 输入电压
        - 负载电流:I_o = I_in = U/Z
        - 功率因数:λ = R/Z
    3. 如果角度大于移相角最小值(不考)
### 3. 其他交流电力控制电路
#### 3.1 交流调功电路
1. 交流调压电路:调整晶闸管触发角，控制每个周期内的导通时刻，来控制输出电压有效值
2. 交流调功电路:在周期分隔的0点进行控制，开通n个周期，关断m个周期，算m+n个周期的功率

## 考点
1. 画波形
2. 阻性负载
    - U_o，I_o，I_VT，λ
3. 阻感负载
    - 角度临界值，U_o，I_o，I_VT
4. 调压/调功的区别与适用
    - 调压:适用于调光，电动机(调完电压立马变化)
    - 调功:适用于调热(变化慢，调电压影响不大的)
