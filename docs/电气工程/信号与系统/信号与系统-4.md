## 一、信号分解为正交信号
1. 正交函数
    - 函数矢量积=0
2. 正交函数集
    - 集合内任意两个函数两两正交
3. 完备正交函数集
    - 集合内函数两两正交的同时，函数多到可以表示集合内任意一个函数
4. 两组典型的正交完备函数集
    - 三角函数集:1,sin(wt),cos(wt)
    - 虚指数函数集:e^jwt
5. 任意信号可以分解为正交函数的和

## 三、周期信号的频谱
1. 单/双边谱
    - 单边谱:对周期信号用三角形式傅里叶级数分解
    - 双边谱:对周期信号用复指数形式傅里叶级数分解
2. 周期信号频谱特点
    - 离散性:频谱是一个离散信号，只在基波频率的整数倍出现
    - 谐波性:每根谱线对应一个谐波分量
    - 收敛性:谐波次数增大，幅度减小
3. 频谱图像的周期分析
    - 谱线间隔:1/T
    - 包络零点:m/τ(τ为脉冲宽度,τ=占空比D*周期T)
        - 零点之间的谱线数量:`(m/t)*T = m*(T/t)`
    1. T不变，τ变小
        - 频谱展宽，幅值降低
    2. τ不变，T变大
        - 谱线间隔变大，但是零点间的谱线数量增多  
4. 频谱图像的收敛分析
    1. 谐波次数越高，幅值越接近0
    2. 谐波趋于0的速度:方波1/n。三角波1/n²，抛物线1/n³，正弦波没有谐波(越平滑越快)
5. 谐波频率分析
    1. 低频波:低频波变化慢，主要展现事物大体轮廓
    2. 高频波:高频波展示事物细节
6. 频带宽度
    - 频谱中能量主要占据的频率范围区域
        - 第一对包络零点内的频谱大约占了90%的能量
        - 一般把第一对包络零点所在区域当作频带宽度
