## 一、LTI离散系统的响应
1. 差分方程
    - 序列，相邻两项之差为差分
2. 求解差分方程
    1. 迭代法
        - 要求的y(k)，方程里有，迭代几项求出来
    2. 经典法
        - 通解+特解
            - 依旧通解根据特征根选形式
            - 特解根据激励选形式
        - 和微分方程求解过程一样
3. 零输入响应
    - 求特征根
    - 写通解格式
    - 带入题目给的y[n1],y[n2]
4. 零状态响应
## 二、单位序列与单位序列响应
1. 单位脉冲序列
    1. 图像
        - 1，k=0
        - 0，k≠0
    2. 特性
        1. +/-:f(t)+/-f(t)
        2. 延时:f(t+k)
        3. 取样:与连续函数时的公式一样
        4. 偶函数
2. 单位阶跃序列
    1. 图像
        - 1，k>0
        - 0，k<0
    2. 特性
        1. +/-
        2. 延时
3. 单位脉冲响应及求解
4. 单位阶跃响应及求解
> 这时候，响应只看零输入响应
