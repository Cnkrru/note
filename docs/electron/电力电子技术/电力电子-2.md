## 电力电子器件概述
### 1. 电力电子系统的组成
1. 主电路
2. 控制电路(控制、驱动、保护)
### 2. 电力电子器件特点
1. 处理电功率的能力远大于信息电子器件
2. 一般工作在开关状态
3. 需要信息电子电路控制
4. 功率损耗远大于信息电子器件，需要散热器
### 3. 电力电子器件的损耗
1. 通态损耗(损耗的主要原因)
2. 断态损耗
3. 开关损耗(当开关频率很大时,开关损耗为主要原因)
    - 开通损耗
    - 关断损耗
> 主电路和控制电路要进行电气隔离
### 4. 电力电子器件的分类
1. 按控制程度分类
    1. 不可控
    2. 半控
    3. 全控
2. 按驱动信号分离
    1. 电流驱动
    2. 电压驱动
3. 按载流子参与导电的情况分离
    1. 单极型
    2. 双极型
    3. 复合型
## 不可控器件——电力二极管
### 一、结构与原理
#### 1. 电力二极管的结构
PiN，在PN结基础上，增加了一个中间低参杂浓度区,该区域的特性接近于本征半导体，使得电力二极管更难导通，也能承受较大的电压
- 如何应对更难导通的问题(电导调制效应)
    - PN结正向电流较小时，电力二极管的阻值很大
    - PN结正向电流较大时，电力二极管的阻值变小
> 电导调制效应使得电力二极管的管压降始终不大
#### 2. 电力二极管工作原理

|状态|正向导通|反向截止|反向击穿|
|---|---|---|---|
|I|正向大|0|反向大|
|U|1V|反向大|反向大|
|阻态|低阻|高阻|---|

#### 3. 击穿方式
1. 雪崩击穿
2. 齐纳击穿
    - 这两个由于反向电压过大导致(电击穿)
3. 热击穿
    - 由于电击穿生热过多，导致二极管结构烧坏
### 二、特性
#### 静态特性
- 和普通二极管一样
#### 动态特性
1. 开启
    - 电压先增大，增大到一个峰值，开始下降
    - 电流增大，增大到一定值，保持不变
2. 关断
    - 电压先减小，再反向增大，增大到峰值，下降
    - 电流与电压变化类似
    - 反向恢复时间 = 延迟时间(电流反向增大)+下降时间(电流反向减小)
### 三、参数
1. 正向压降
2. 反向重复峰值电压
    - 击穿电压的2/3
3. 正向平均电流(I_FV)
    - 最大电流有效电流(最大电流有效值)为:1.57I_FV
4. 反向恢复时间
5. 最高工作温度
6. 浪涌电流
### 四、类型
1. 普通电力二极管
    - 开关频率不高
    - 反向恢复时间较长
    - 正向额定电流和反向额定电压可以很高
2. 快恢复电力二极管
    - 反向恢复时间很短
3. 肖特基电力二极管
    - 反向恢复时间短
    - 正向恢复无正向脉冲
## 半控型器件——晶闸管
### 一、结构原理
#### 1. 结构原理
PNPN(PNP+NPN)
1. 阳极+阴极+门极(控制极)
    - 正向电压+门极电压(大于维持电压) -> 开
    - 导通后，门极不可控制其关断
2. 门极未加电压
    - 加正向电压:P(NP)P阻断
    - 加反向电压:(PN)(PN)阻断
3. 门极加电压后
    - 两个三极管的三条支路组成的回路循环正促进，电流迅速增大，使两个三极管饱和
#### 2. 其他导通情况
1. 正向电压过大，电击穿
2. 正向电压变化率过大
3. 温度过高，热击穿 -> 烧坏了
4. 光触发(唯一可控)
#### 3. 关断方法
去掉阳极加的反向电压
- 阳极加反向电压
- 设法使流过晶闸管的电流降低到接近0的某一数值以下(维持电流)
### 二、特性
#### 1. 静态特性
1. 加反向电压时，无论门极有无电压，均不导通
2. 加正向电压时，只有门极有触发电流才导通
3. 晶闸管一旦导通，门极失去作用
4. 晶闸管关断方法
- 正向特性:没加门极电压，随着正向电压加大，达到转折电压，最终击穿，晶闸管上电压逐渐下降到1V(转折电压也下降)，电流迅速升高
- 反向特性:和普通二极管一样
#### 2. 动态特性(暂时没记录完整)
- 电流:
    - 开通:延迟时间(电流几乎为0)+上升时间
    - 关断:
- 电压:
    - 开通:
    - 关断:
### 三、参数
#### 1. 电压定额
1. 正向
    - 通态重复峰值电压
    - 断态重复峰值电压
2. 反向重复峰值电压(小于反向击穿电压)
#### 2. 电流定额
1. 通态平均电流(I_FV)
    - 有效值是其1.57倍
2. 维持电流
    - 导通所需最小电流
3. 擎住电流
4. 浪涌电流
#### 3. 动态参数
1. 通态电流临界上升率
2. 断态电压临界上升率
### 四、派生器件
1. 双向晶闸管
    - 图形是普通晶闸管根据原点对称一下
2. 快速晶闸管
    - 开关时间减少，电压变化率和电流变化率增大
    - 缺点:电压电流定额不适合做大
3. 逆导晶闸管
4. 光控晶闸管
## 典型全控型器件
### 一、门极可关断晶闸管(GTR)
#### 1. 结构原理
1. 可以通过门极加负脉冲关断
    - 加负脉冲 -> 经过正循环 -> 电流减小到维持电流以下
2. 特点(暂时没写)
#### 2. 特性(动态特性)
1. 开通:和普通晶闸管一样
2. 关断:储存时间+下降时间+尾部时间
#### 3. 参数
1. 开通时间
2. 关断时间
3. 最大可关断阳极电流(I_ATO)
4. 电流关断增益(β_off)
    - I_ATO/I_GM
        - I_GM:门极负脉冲电流最大值
### 二、电力晶闸管
#### 1. 结构原理
1. 工作原理:与晶闸管相同
2. 特点
    1. 耐压高
    2. 电流大
    3. 开关特性好
    4. 通常按照达林顿接法接(可以增大放大倍数)
#### 2. 特性
1. 静态特性
    - 图和二极管的静态特性的图一样，一般工作在截止区和饱和区(上下两区)
2. 动态特性
    1. 上升:延迟时间+上升时间
    2. 下降:储存时间+下降时间
#### 3. 参数
1. 最高工作电压
2. 集电极最大允许电流
3. 集电极最大耗散功率
#### 4. 二次击穿和安全工作区
1. 一次击穿:集电极电压升高到击穿电压
2. 二次击穿:电压超过安全电压，二次击穿，晶闸管压降迅速下降，元件损坏
3. 安全工作区:
    - 最高电压
    - 最大耗散功率
    - 集电极最大电流
    - 二次击穿临界值
### 三、电力MOSFET
#### 1. 结构原理
1. 特点
    1. 驱动电路简单，需要驱动功率
    2. 开关速度快，工作频率高
    3. 热稳定性由于电力晶闸管(GTR)
    4. 电流容量小，耐压低，适用于功率不超过10KW的电力电子装置
2. 工作原理
    1. 截止:漏极加正电压，栅极P基区与N漂移区之间形成的PN结J_T反偏，漏源之间无电流流过
    2. 导电:在栅源极间加正电压Uas，Uas>U_T时，P型半导体形成反型层，J_T消失，导通
#### 2. 特性
1. 静态特性
    - 和二极管的图一样
        - 非饱和(二极管饱和区)+饱和区(二极管放大区)+截止区(二极管截止区)
        - 工作在非饱和区/截止区
2. 有通态电阻，温度升高，因为正温度系数的缘故，电阻升高
3. 是工作频率最高的电力电子器件
### 四、绝缘栅极双极晶闸管
#### 1. 原理结构
1. 中大功率的电力电子器件
2. MOSFET+GTR
#### 2. 特性
1. 静态特性
    - 转移特性:同MOSFET(二极管正常导通图像)
    - 输出特性:同GTR(二极管三区)
#### 3. 参数
1. 最大集射极间电压
2. 最大集电极电流
3. 最大集电极功率
