# 动态数组

## 属性

- 长度:`length()`

## 方法

1. 增
    - 压栈:`push()`
    - 拼接:`concat()`
    - 插入:`splice(,,)`
2. 删
    - 出栈:`pop()`
    - 去除:`splice(起,个数)`
3. 改
    - 替换:`splice(起,个数,新元素)`
    - 反转:`reverse()`
    - 排序:`sort(比较函数)`
4. 查
    - 首个:`find(条件)`
    - 截取:`slice(m,n)`
    - 过滤:`fliter(条件)`
    - 重组:`map(条件)`
5. 遍历
    - 循环:`for_of`
    - 循环回调:`forEach(条件)`
