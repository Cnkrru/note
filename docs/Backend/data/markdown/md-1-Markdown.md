## 简介
写文档用的，最常用，能转成HTML，有拓展语法(文档站经常会自定义)
## 写法
### 1. 标题
```markdown
# 一级标题
## 二级标题
```
以此类推，#与标题间必须有空格
### 2. 段落
```markdown
第一段

第二段
```
markdown中段落间间距一行来表示不同段落
### 3. 文本样式
```markdown
粗体    **粗体**
斜体    *斜体*
粗斜体  ***粗斜体***
-------------------
删除线  ~~删除文本~~
下划线  <u>下划线文本</u>
```
### 4. 分割线
```markdown
1.---              分割线

2.回车              markdown直接回车换行即可，也可以在文本后加上两个空格来表示换行

3.```行内代码```    行内代码

4.>内容             引用 

5.[^1]:脚注         脚注
```
1. markdown使用三个及以上"-"来表示分割线
2. 在表格中换行，使用<br>标签

### 5. 转义字符
```markdown
\   反斜线

`   反引号

*   星号

_   下划线

{}  花括号

[]  方括号

()  小括号

#   井字号

+   加号

-   减号

.   英文句点

!   感叹号
```
以上若想正常显示，在前面添加一个\即可

### 6. 列表
#### 无序列表
```markdown
- 项目1
- 项目2
- 项目3
```
#### 有序列表
```markdown
1. 项目1
2. 项目2
3. 项目3
```
#### 任务列表
```markdown
- [ ] 任务1
- [ ] 任务2
- [ ] 任务3
```
### 7. 表格
#### 基本表格

```markdown
|  表头   | 表头  |
|  ----  | ----  |
| 单元格  | 单元格 |
| 单元格  | 单元格 |
```

#### 设置表格对齐方式
```markdown
| 左对齐 | 右对齐 | 居中对齐 |
| :-----| ----: | :----: |
| 单元格 | 单元格 | 单元格 |
| 单元格 | 单元格 | 单元格 |
```
### 8. 链接
#### 行内链接：
```markdown
[链接文字](https://www.example.com)
<https://www.example.com>
```
#### 参考链接：
```markdown
[链接文字][1]
[1]: https://www.example.com
```
### 锚点
#### 文章锚点：
```markdown
1. 行内锚点：[锚点文字](#锚点id)
2. 参考锚点：[锚点文字][1]
    [1]: #锚点id
```
#### 手动创建锚点：
1. 在需要创建锚点的位置添加HTML标签：`<a id="锚点id"></a>`
2. 在文章中使用锚点：[锚点文字](#锚点id)
### 9. 图片
#### 行内图片：
```markdown
![图片描述](https://www.example.com/image.jpg)
```
#### 参考图片：
```markdown
![图片描述][1]
[1]: https://www.example.com/image.jpg
```
#### img标签写法:
```html
<img src="https://www.example.com/image.jpg" alt="图片描述" />
```
#### 点击图片跳转链接的markdown写法：
```markdown
[![alt](图片URL)](链接URL)
```
