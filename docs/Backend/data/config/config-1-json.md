## 简介
常用于前后端传递数据/项目配置文件
## 详细
1. 格式:`key:value`
2. 类型:
  - key:string
  - value:number,string,boolean,null,array,object(这里用的是JavaScript的数据类型)
3. 注释:不能写，但是vscode把文件类型改成`json with commens`,写`//`注释也没啥影响，编辑器不报错
```json
{
  "字符串": "Hello, JSON!",
  "数字": 123.45,
  "整数": 42,
  "布尔值": true,
  "空值": null,
  "数组": ["苹果", "香蕉", "橙子"],
  "对象数组": [
    {
      "id": 1,
```
