## 简介

列表与表格：无序列表、有序列表、定义列表，以及表格的结构、属性和单元格合并。

## 详细

### 1. 无序列表

- ul嵌套li
  - 注意事项：
    - ul里只能写li
    - li里可以写p/h等

> 部分组件需要把实心点去掉

### 2. 有序列表

- ol嵌套li

### 3. 定义列表

- dl嵌套dd/dt
  - 说明：
    - dt是标题，dd是描述
    - 一般用于页脚，做一个尾部服务栏目

> 没写过

### 4. 表格
- table嵌套tr，tr嵌套td/th
- table：说明这是一个表格
- tr：一个tr开启一行
- th：这一行的头单元格
- td：这一行的内容单元格
