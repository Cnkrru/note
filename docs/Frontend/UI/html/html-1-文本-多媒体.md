## 1. 文本相关标签
- h：标题
- p：段落

> 带基础样式的span，实际写的时候没啥用，很少写
## 2. 多媒体相关标签
### 图像标签
- img（单标签）
  - src：图像路径
  - alt：失败替换文本
  - title：图像名称
  - width：图像宽度
  - height：图像高度

> 一般只写个src,alt和title，宽高一般CSS来弄
### 音频标签
- audio
  - src：路径
  - controls：控制面板
  - loop：循环播放
  - autoplay：自动播放

> 很少写
### 视频标签
- video
  - src：路径
  - controls：控制面板
  - loop：循环
  - muted：静音播放
  - autoplay：自动播放（自动需要配合静音播放一起使用）

> 基本没写过
